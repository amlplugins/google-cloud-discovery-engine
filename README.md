# @amlplugins/google-cloud-discovery-engine

Native `@google-cloud/discoveryengine` SDK re-exported under the `@amlplugins` namespace.

> Discovery Engine.

## Install

```bash
npm install @amlplugins/google-cloud-discovery-engine
```

## Use

```ts
import { /* named exports from @google-cloud/discoveryengine */ } from "@amlplugins/google-cloud-discovery-engine";
// or
import sdk from "@amlplugins/google-cloud-discovery-engine";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
